# Sales Dashboard 📊

An interactive dashboard built for analyzing sales meeting performance using **Looker Studio**, **MongoDB**, and **Cloud Run APIs**.

## ✨ Features

- Dynamic field selection and date filtering in Looker Studio
- Real-time metrics served through Cloud Run APIs
- Integration with MongoDB for flexible, scalable data querying
- Built-in support for Google Apps Script-based connectors

## 🧱 Tech Stack

- Python (Flask on Cloud Run)
- MongoDB Atlas
- Google Looker Studio
- Google Apps Script
